# 思考能力评估与重建

**Thinking Assessment & Reconstruction** · [English](./README.en.md)

> 一套基于认知科学文献的**思考能力体检 + 12 周重建训练系统**：90 分钟评估产出你的六维思考画像，全自动诊断并生成个性化训练处方；全程在浏览器本地完成，无后端、无注册、不收集任何数据、不调用任何大模型。

## 它解决什么问题

"想提升思考能力"之所以常常失败，是因为它被当成玄学。过去 50 年的认知科学研究给出了清晰结论：

1. 思考质量主要取决于**反省心智**（愿不愿意、会不会调用慢思考审查直觉），而它**可以训练**（Stanovich; Kahneman）。
2. 思考能力可测量：**抗偏见、校准度、元认知、结构化、开放性、决策闭环**六个维度。
3. 去偏见训练效果真实且可维持（Morewedge et al., 2015），但难点在**迁移**——所以本系统的核心是**带反馈的日常刻意练习**，不是知识灌输。

## 核心特性

- ✅ **全自动**：提交即出雷达图 + 诊断 + 训练处方，零人工介入
- ✅ **纯本地**：单文件 HTML，评分引擎全部开源可审计，无任何数据上传
- ✅ **中英双语**：界面按浏览器语言自动切换，可手动切换
- ✅ **可溯源**：每道题与每条评分规则都对应 [参考文献](./docs/05-参考文献.md)
- ✅ **可复测**：导出 JSON，12 周后复测自动对比六维变化

## 快速开始（3 步）

1. **在线评估**：打开 [assessment.html](./tools/assessment.html)（部署后可通过 GitHub Pages 直接访问），按引导完成 A–C 部分（约 90 分钟）
2. **获得报告**：提交后立即生成六维雷达图、自动诊断与个人处方；导出 JSON 存档
3. **开始训练**：按处方进入 [12 周训练系统](./docs/03-训练系统.md)，配合 [校准与概率训练馆](./tools/training.html) 与 [模板库](./docs/04-模板库.md) 每周练习

> 没有网络也可以：下载本仓库，用浏览器直接打开 `tools/` 下的两个 HTML 文件即可。

## 评估的六个维度

| 维度 | 含义 |
|---|---|
| 理性 / 抗偏见 | 抵抗锚定、沉没成本、合取谬误、基率忽视等直觉错误 |
| 校准度 | 你说"90% 把握"的事是否真有约 90% 会成真 |
| 元认知 | 实时觉察自己正在怎么思考、被什么影响 |
| 结构 / 深度 | 定义问题、拆解、挖假设、追根因 |
| 开放性 | 主动寻找反面证据、钢人论证 |
| 决策闭环 | 写下来、记预测、事后复盘 |

## FAQ

**这是心理测验吗？** 不是。它是基于认知科学范式的自我训练参考工具，不构成心理测量学诊断，也不构成医疗/投资建议。

**我的答案会被上传吗？** 不会。所有计算都在你的浏览器里完成，本仓库没有任何后端与统计脚本。

**多久复测一次？** 建议 12 周训练结束后复测。复测时导入基线 JSON 即可查看六维变化曲线。

**A2/C 部分为什么是自评？** 开放题在无大模型条件下的严谨做法是"机器引导的结构化自评"：程序展示标准要点与评分标准，你勾选，程序汇总。规则完全开源，可对照 [02-答案与诊断](./docs/02-答案与诊断.md) 审计。
