# 示例评估报告（匿名样例）

> 这是一份**虚构的示例报告**，用于展示在线评估（`tools/assessment.html`）的输出格式与诊断逻辑。数值不代表任何真实用户。

**评估日期**：2026-XX-XX ｜ **用时**：约 85 分钟

## 一、原始得分

| 部分 | 得分 | 说明 |
|---|---|---|
| A1 认知反射 | 3 / 4 | 第 2 题直觉错误且未改正 |
| A2 偏见情境 | 4.5 / 6 | 基率题与框架效应题失分 |
| A3 概率直觉 | 1 / 4 | 医学检测答 90%（基率忽视） |
| A4 校准 | 5 / 10 命中 | 90% 把握区间只命中一半 |
| B 行为自评 | 结构 65% / 开放 60% / 量化 40% / 元认知 73% / 闭环 45% | |
| C 实战 | 12 / 21 | 有结构但缺证据标注与改判条件 |

## 二、六维画像（雷达图数值）

| 维度 | 百分比 | 水平 |
|---|---|---|
| 理性 / 抗偏见 | 61% | 中 |
| 校准度 | 48% | 偏低 ⚠️ |
| 元认知 | 70% | 中上 |
| 结构 / 深度 | 64% | 中 |

**形状判读**：元认知与结构尚可，但"校准度"与"决策闭环"构成双凹口——典型"想得明白、但对自己的把握度没把握、且想法不落纸面"的画像。

## 三、自动诊断（示例）

1. **A4 命中 ≤ 6** → 显著过度自信（研究显示人群平均命中率仅约 50%）。**首要任务：校准训练（模块 C）**——每日"万物皆估"+ 每周训练馆校准套题。
2. **B"决策闭环" ≤ 50%** → 思考不落地。**次要任务：决策日志 + 月度复盘（模块 E）**，先只做"每天一句话日志"这一个动作。
3. **A1 尚可但 A3 低** → 知识没有变成反射：概率题需自然频率法刻意练习（模块 C）。

## 四、自动处方（示例）

- **第 1–2 周**：只做两件事——决策日志每天一句话；每天估一个数量级并记录。
- **第 3–4 周**：加入每周 45 分钟深度思考会（用 04 文件工作表），开始校准套题（训练馆 B 组起）。
- **第 7–8 周**：校准复测，目标命中 ≥ 7/10；月度预测核对。
- **第 12 周**：导入本报告的 JSON 复测对比，看六维变化趋势。

> 通用规则：永远先修最低的 1–2 个维度，坚持 4 周，再评估下一个。贪多必败。
