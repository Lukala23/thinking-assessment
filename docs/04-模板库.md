## 附：偏见识别速查卡（贴在你看得见的地方）

| 偏见 | 一句话识别 |
|---|---|
| 确认偏误 | 只在找支持自己的证据 |
| 沉没成本 | "都投入这么多了" |
| 锚定 | 被第一个数字带跑了 |
| 框架效应 | 换个说法我的选择就变了 |
| 幸存者偏差 | 只看到成功的样本 |
| 基率忽视 | 忽略了"这类事通常怎样" |
| 规划谬误 | 计划总比实际顺利 |
| 合取谬误 | 细节越丰富越觉得真 |
| 可得性偏差 | 最近/最轰动的例子主导判断 |
| 动机性推理 | 结论先行，证据是事后找的 |
| 过度自信 | 把握度 > 实际命中率 |
| 后见之明 | "我当时早就知道" |
